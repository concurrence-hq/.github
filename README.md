# Concurrence public repositories

This repository owns the [Concurrence organization profile](profile/README.md) and community guidance inherited by public repositories that do not provide their own copy.

- [Choose a public SDK or tool](profile/README.md#public-product-surfaces)
- [Contribute a fix or report a bug](CONTRIBUTING.md)
- [Report a vulnerability privately](SECURITY.md)
- [Get implementation or account support](SUPPORT.md)

Product concepts, integration instructions, and current API references live in the [unified documentation](https://docs.concurrence.com). Each SDK repository owns its package code, executable examples, and release history.
